`npm run check` зараз червоний. Знайди причину в коді продукту в `src/` і виправ її.

Обмеження:

- не змінюй тести (`*.test.*`), фікстури, `openspec/`, `docs/run-budget.md`, `docs/run-task.md` і `scripts/agent-run.mjs`;
- не запускай встановлення пакетів;
- коли виправлення зроблене, коротко напиши, що саме змінив і чому.

Перевірку запускає не агент: після твоєї спроби її запустить обгортка.
