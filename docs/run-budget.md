# Бюджет прогону · day05

Ці рядки читає `scripts/agent-run.mjs`. Інших лімітів у прогоні немає: у скрипті лише перетворення одиниць.

- attempts: 6
- minutes: 20
- usd: 3
- stall: 2

## Що означає кожне число

- `attempts` — скільки разів агента можна викликати за один прогін.
- `minutes` — скільки часу займає весь прогін, від старту до зупинки.
- `usd` — стеля в доларах на весь прогін; кожен виклик отримує лише залишок.
- `stall` — скільки червоних перевірок поспіль допустимо, коли агент за спробу нічого не змінив.

## Що вважається червоним

Ненульовий код виходу `npm run check`. Не тон звіту агента.

## Що агент не має права змінювати

Цей файл, `docs/run-task.md`, `scripts/agent-run.mjs`, будь-який `*.test.*`, фікстури й `openspec/`.
Запобіжник звіряє їх до старту й після кожної спроби.
